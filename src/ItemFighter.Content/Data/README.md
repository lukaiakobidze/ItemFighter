# Game content

**Everything here is placeholder starter content** to test the engine. Luka designs the real items,
characters, enemies and passives; see `docs/content-guide.md` for how to write and rebalance them.

- `items/` – board items (one file each)
- `passives/` – slotless passives
- `characters/` – playable characters
- `enemies/` – enemies, and `enemies/abilities/` for their abilities
