# Game content

Luka's content: 12 common items and 16 rare ones (2026-10-12 and 2026-10-15), 6 enemies, the Silver Knight. See `docs/balancing.md` for where every number lives and `docs/content-guide.md` for how to write content.

- `items/` – board items (one file each)
- `passives/` – slotless passives (none yet)
- `characters/` – playable characters
- `enemies/` – enemies, and `enemies/abilities/` for their abilities and passives
- `rules.json` – burn, poison, chill, freeze, nail damage, fight time limit, minimum cooldown
- `run.json` – gold, prices, shops, run length, enemy difficulty, reward odds, bosses
