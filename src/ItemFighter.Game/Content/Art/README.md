# Art

Drop PNG files here. The file name is the content id:

- `Items/fire_flask.png`
- `Enemies/ember_king.png`
- `Characters/wanderer.png`
- `Passives/iron_skin.png`

Square images work best (for example 256×256); they are scaled to fit and keep their shape. Transparent backgrounds are fine. A missing or broken file shows a coloured placeholder with the name, so the game never crashes over art.

While the game is running, press **F5** to reload art and content after you change files.
